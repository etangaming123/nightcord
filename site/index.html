Nightcord

A web-based messaging app, built for selfhosting. A parody of Discord.

Guilds, DMs, friends and custom emoji on a server you run yourself, for the people you actually talk to. It's like the real thing, minus the ads and the Nitro upsell. Plus a few bugs, probably.

What's in it?

💬

Chat

Guilds with channels, categories, roles and permissions. Replies, reactions, pins, search, markdown, spoilers, polls and slash commands. Link previews that look like Discord's (tweets and YouTube included), and the same Twemoji on every device. Custom emoji and stickers work everywhere, for everyone, free. (Take that, Nitro.)

👋

Friends

Friend requests by username, message requests from people you don't know yet, blocking, group DMs, and an inbox for server announcements. Keep a private note on someone. Hop between accounts and servers from one switcher.

🏠

Yours

One small Python server and one SQLite file. You own the data and set the rules. Link previews are fetched by the server, so the sites people link to never see your address. See what your storage goes on, back everything up with one command, and swap the logo and sounds by replacing a file. Hand out your own badges, blue Verified check included.

Let's get started!

  1. Someone runs a server. A Python 3.11+ box: a spare PC, a Raspberry Pi, a cheap VPS. The README walks through it.
  2. Everyone opens the client. It's this website. Nothing to install.
  3. Type in the server's address, make an account and say hi.

Before you dive in

  • This is vibecoded by Claude, have fun :) It works, it has tests, but nobody has audited it.
  • Built for personal use: a few friends, a big friend group at most. It's not meant to be a big public service.
  • Server owners can see your IP address, and they can read everything on their server. Only join servers run by people you trust.
  • Nightcord is a parody. It isn't affiliated with or endorsed by Discord.
